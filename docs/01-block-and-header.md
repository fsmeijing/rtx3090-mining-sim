# 1. 区块与区块头

## 什么是区块？

比特币区块链就像一本**公共账本**，每隔约 10 分钟新增一页，这一"页"就叫**区块（Block）**。每个区块里记录着一串交易，以及一个指向前一页的"回执"——这样所有页就连成一条链。

## 区块头：区块的"身份证"

每个区块的开头有固定 **80 字节**的摘要信息，叫**区块头（Block Header）**。它只有 6 个字段：

| 字段 | 大小 | 作用 |
|---|---|---|
| Version | 4 字节 | 版本号，比如 1 |
| PrevHash | 32 字节 | 上一个区块的哈希（链条的"扣环"） |
| MerkleRoot | 32 字节 | 本区块所有交易的指纹 |
| Timestamp | 4 字节 | 打包时间（Unix 秒数） |
| nBits | 4 字节 | 压缩格式的难度目标 |
| Nonce | 4 字节 | 挖矿时不断尝试的随机数 |

创世区块（第 0 块）的真实字段：

```
Version     = 1
PrevHash    = 0000...0000（前面没有区块，所以是 64 个 0）
MerkleRoot  = 4a5e1e4baab89f3a32518a88c31bc87f618f76673e2cc77ab2127b7afdeda33b
Timestamp   = 1231006505（2009-01-03 18:15:05 UTC）
nBits       = 0x1d00ffff
Nonce       = 2083236893
```

## 字节序小知识（很重要！）

同样的数字，在电脑里"从哪头开始存"有两种习惯：
- **小端（little-endian）**：低位字节放前面（比特币的区块头字段这么存）
- **大端（big-endian）**：高位字节放前面（人看哈希时的习惯顺序）

比如 Nonce = 2083236893 = 0x7c2bac1d，在区块头里存的是 `1dac2b7c`（小端），
但哈希展示时用大端。**本项目代码里反复出现的"字节反转"就是这件事**，
也是初学者最容易搞错的地方。

## 本项目怎么验证？

```bash
python3 -m bitcoin_pow --verify
```

程序会把上面 6 个字段拼成 80 字节区块头，算出双重 SHA-256，
和真实的创世哈希 `000000000019d6689c...8ce26f` 比对，输出 `MATCH`。
