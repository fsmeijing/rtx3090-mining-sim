# 2. SHA-256 工作原理

## 一句话理解

SHA-256 是一台"**数字搅拌机**"：你把任意长的数据倒进去，它总是吐出 32 字节（256 位）的"果汁"。只要输入变哪怕 1 个字节，输出就会变得完全不同、无法预测。

## 三个关键性质

1. **确定性**：同样的输入永远得到同样的输出。
2. **雪崩效应**：输入改 1 个比特，输出的约一半比特都会翻转。
3. **单向性**：从输出反推输入，除了一个个试，没有捷径。

试试看（Python）：

```python
from bitcoin_pow.sha256d import sha256
print(sha256(b"abc").hex())
# ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

把 `abc` 改成 `abd`，输出就完全变了——这就是雪崩效应。

## SHA-256 内部在做什么？（简化版）

1. **分组**：把输入切成 64 字节一块，最后一块做特殊填充。
2. **初始状态**：8 个 32 位数（人话：8 个"缸"），取自前 8 个质数的平方根小数部分。
3. **64 轮压缩**：每轮把一个数据字和常量（前 64 个质数的立方根小数部分）"搅拌"进 8 个缸里，用的只是加法、移位、异或这些基本操作。
4. **输出**：8 个缸拼起来就是 256 位摘要。

本项目的 CUDA 内核（`cuda/sha256d.cuh`）就是把这套"搅拌流程"用 GPU 显卡的语言重写了一遍，让显卡里**两万多个工人同时搅拌不同的区块头**。

## 双重 SHA-256（SHA256d）

比特币对区块头做**两次**哈希：

```
H = SHA256( SHA256( 80字节区块头 ) )
```

为什么做两次？中本聪没有留下书面解释，普遍认为是为了抵御
"长度扩展攻击"这一类针对单次 Merkle–Damgård 结构哈希的攻击。
对教学实验来说，你只需记住：**比特币挖矿算的是双重 SHA-256**。

## 见证创世哈希

```bash
python3 -m bitcoin_pow --verify
# 计算 H      = 000000000019d6689c085ae165831e934ff763ae46a2a6c172b3f1b60a8ce26f
```

这串以很多 0 开头的输出，就是全世界第一个比特币区块的双重 SHA-256。
